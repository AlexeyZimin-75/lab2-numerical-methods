# Лабораторная работа №2. Вариант 7 {#mainpage}

## Постановка задачи
С точностью \f$ \varepsilon = 0.5 \cdot 10^{-5} \f$ найти наименьший положительный корень уравнения

\f[ f(x) = 1 + \sin x - 1.15 e^{-x} = 0 \f]

методом Ньютона и методом простых итераций (МПИ).

## Локализация корня
\f$ f(0) = -0.15 < 0 \f$, \f$ f(0.1) = 0.0593 > 0 \f$, следовательно, корень лежит на отрезке **[0; 0.1]**.

\f$ f'(x) = \cos x + 1.15 e^{-x} > 0 \f$ на \f$ [0; \pi/2] \f$, поэтому функция возрастает,
корень на отрезке единственный и является наименьшим положительным.

## Метод Ньютона
- Расчётная формула: \f$ x_{n+1} = x_n - f(x_n)/f'(x_n) \f$.
- На [0; 0.1]: \f$ f'(x) > 0 \f$, \f$ f''(x) = -\sin x - 1.15 e^{-x} < 0 \f$ — знакопостоянны.
- Начальное приближение по условию Фурье \f$ f(x_0) f''(x_0) > 0 \f$: **x0 = 0**.
- \f$ m_1 = \min|f'| \approx 2.0356 \f$, \f$ M_2 = \max|f''| = 1.15 \f$.
- Условие выхода: \f$ |x_n - x_{n-1}| \le \sqrt{2 m_1 \varepsilon / M_2} \approx 0.0042 \f$.

## Метод простых итераций
- Вид для итераций: \f$ \varphi(x) = x - 0.47 f(x) \f$.
- \f$ \varphi'(x) = 1 - 0.47 f'(x) \in [-0.0105;\ 0.0433] \f$, \f$ q = 0.0433 < 1 \f$;
  \f$ \varphi(0) = 0.0705 \f$, \f$ \varphi(0.1) = 0.0721 \f$ — отрезок отображается в себя.
- Вид \f$ x = \ln 1.15 - \ln(1 + \sin x) \f$ отвергнут: \f$ |\varphi'(0)| = 1 \f$.
- Условие выхода: \f$ |x_n - x_{n-1}| \le \frac{1-q}{q} \varepsilon \approx 1.1 \cdot 10^{-4} \f$.
- Априорная оценка: \f$ x_0 = 0.05 \f$, \f$ n \ge 2.67 \f$, то есть **n = 3**.

## Результаты

| Метод   | Начальное приближение | Фактическое число итераций | Полученный корень |
|---------|-----------------------|----------------------------|-------------------|
| Ньютона | 0                     | 2                          | 0.0711159         |
| МПИ     | 0.05                  | 3                          | 0.0711161         |

## Выводы
Оба метода дали корень \f$ x^* \approx 0.07112 \f$ с требуемой точностью.
Метод Ньютона сошёлся быстрее (2 итерации) благодаря квадратичной скорости сходимости.
МПИ потребовал 3 итерации, что совпадает с априорной оценкой; малое значение q
обеспечено удачным выбором параметра λ.
